# What I Use

現在の開発環境、使用するツールです。

## Tech Stack

### Languages

- [TypeScript](https://www.typescriptlang.org/) as my main programming language.
- [Rust](https://rust-lang.org/)
- [python](https://www.python.org/)

### Frameworks

- [React](https://reactjs.org) for UI creation.
- [Tailwind CSS](https://tailwindcss.com/) for styling.
- [Remix](https://remix.run/) for full stack web.

### Testing

- [Vitest](https://vitest.dev/) and [Jest](https://jestjs.io/) for unit testing.
- [React Testing Library](https://testing-library.com/react) for React testing.
- [Cypress](https://www.cypress.io/) for integration and E2E testing.

### Deployment

- [Vercel](https://vercel.com/) as my deployment platform.

## Tools

### Browser

- [Firefox Developer Edition](https://www.mozilla.org/firefox/developer/) as my main browser.
- [Chrome Dev](https://www.google.com/chrome/dev/) as my test browser.

### Terminal

- [WezTerm](https://wezfurlong.org/wezterm/) and [Windows Terminal](https://github.com/microsoft/terminal) as my terminal outside of VSCode.
- [zsh](https://www.zsh.org/) as my shell.

### Editor

- [VSCode](https://code.visualstudio.com) and [Neovim](https://neovim.io) as my IDE/code editor.

### Repository

- [GitHub](https://github.com)

### Communication

- [Slack](https://slack.com)

## Environment

- [WSL 2](https://docs.microsoft.com/windows/wsl/about)
