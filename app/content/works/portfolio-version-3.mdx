## ひとこと

当初はポートフォリオ第三弾として、[NuxtJS](https://nuxtjs.org) で開発を進めていました。コンポーネントが粗方仕上がった頃、Nuxt 2 から Nuxt 3 への移行が始まり、Composition API で開発していたこともあり、 Bridge に移行してみましたが package の大半が使い物にならなくなったので断念しました 😢<br/>
出来るだけ新しい framework をと思うなか、目に留まったのが今回の[Remix](https://remix.run)です。file system に関して Vercel との相性に思うところはあるものの比較的まとまったかなと感じています。<br/>
今回は Google Analytics の代わりにプライバシー優先の umami を採用しています。
